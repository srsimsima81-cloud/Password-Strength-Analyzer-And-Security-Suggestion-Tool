      Password vs Passphrase

      A long, unique passphrase made from randomly selected words can be easier to remember while resisting guessing. Avoid famous quotes and predictable phrases.

      10 Password Security Rules

      1. Use unique passwords.
      2. Prefer longer passwords/passphrases.
      3. Avoid predictable personal information.
      4. Avoid common passwords.
      5. Avoid password reuse.
      6. Use a password manager.
      7. Enable MFA.
      8. Never share passwords.
      9. Watch for phishing.
      10. Change credentials when compromise is suspected or confirmed.

      Real-World Login Security

      Password strength is one control among MFA, secure password hashing, rate limiting, abuse protection, session security, phishing protection, and monitoring.
