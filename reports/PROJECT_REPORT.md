# Project Report

## Abstract
A defensive password-security application that evaluates length, character diversity, common passwords, sequences, keyboard patterns, repetition, dictionary words, predictable structures, optional personal-information overlap, and an entropy-style estimate. A project-defined scoring engine produces a classification and recommendations.

## Objectives
- Demonstrate authentication security concepts.
- Analyze passwords without persistence.
- Detect predictable credential patterns.
- Educate users about passphrases, password managers and MFA.
- Demonstrate secure random generation and separate password hashing.
- Store only safe aggregate analytics.

## Limitations
No single formula perfectly determines password strength. Entropy can be optimistic for human-created passwords. Real-world security also depends on attacker model, password hashing, rate limiting, MFA, phishing resistance, reuse, and account controls.
